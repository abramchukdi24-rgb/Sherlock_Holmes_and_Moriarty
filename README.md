## 🚀 Как запустить
1. Клонируйте репозиторий:
git clone https://github.com/abramchukdi24-rgb/Sherlock_Holmes_and_Moriarty  
cd repo
2. Установите зависимости:  
pip install -r requirements.txt  
3. Запустите проект:  
python app.py
